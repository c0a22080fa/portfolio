## 仕組み

1. 画面から緯度と経度を受け取る
2. Yahoo! の天気情報 API に問い合わせる
3. 結果を「晴れ」「曇り」「雨」に分ける
4. folium で地図を作り、現在地のマーカーに天気を表示する

API キーはコードに直接書かず、置き換え用の文字にしてから公開しています。
